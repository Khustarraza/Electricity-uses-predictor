# Electricity Usage Predictor (PS 68)

Rungta International Skills University – B.Tech CSE

## Description
Loads past monthly electricity usage from `usage.csv`, fits a linear
regression line (`Units = slope × Month + intercept`) using NumPy `polyfit`
(degree 1), predicts usage for a future month, estimates the bill
(Rs. 6 per unit) and plots actual data with the trend line.

## Requirements
- Python 3
- pandas, numpy, matplotlib
